# 轻量写作语料库

这里保存可选的写作方法卡、场景抓手和公开资料研究笔记，不保存小说正史，也不另立文风规则。

## 权威边界

- 正式文风只以 `00_项目总控/语言风格与叙事基调.md` 为准。
- `corpus/` 中的卡片只能帮助观察、研究或组织场景，不能覆盖上位文风、人物档案、情节大纲和用户当前指令。
- 卡片中的步骤、层次和节拍均为可选参考，不是正文必须完成的清单。
- 不因一张卡片提到某种方法，就固定细节数量、表达顺序、情绪强度或场景结构。

## 使用方式

只在当前任务确实需要时读取一至两张相关卡片。先明确场景最重要的表达重点，再选择其中真正有用的方法；不相关的部分直接忽略。

若卡片与正式文风总则冲突，以正式文风总则为准，并及时修正卡片。
