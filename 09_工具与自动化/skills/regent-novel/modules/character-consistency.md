# 人物一致性

用于规划、正文和审稿中的人物校验。目标不是让人物永远理性或永远保持同一种状态，而是让偏差有原因、有过程、有后果。

## 七项核对

1. **目标**：人物此刻想得到、保护或逃避什么。
2. **知识**：人物已经知道什么，通过何种渠道知道。
3. **能力**：专业技能、体能、语言、经验和资源是否足够。
4. **状态**：伤病、疲劳、酒精、恐惧、愤怒和环境压力如何影响动作。
5. **交流状态**：面对当前对象时，人物愿意开放到什么程度；关系阶段和现场压力是否会改变平时表现。
6. **声音**：词汇、句长、直接或回避、幽默、沉默和情绪外露是否符合当前状态，而不是机械展示人物标签。
7. **弧线**：本次变化是否由此前事件积累，而非作者临时需要。

人物偏离通常状态并不自动构成冲突。只要当前关系安全度、话题利害、身体状态或环境压力能够解释，允许人物比平时多说、少说、更直接、更沉默或暂时判断失准。不得用固定台词数量、句长或场景岗位判断人物是否一致。

## 判断级别

- `通过`：行为可由既有目标与状态充分解释。
- `需铺垫`：行为可以成立，但正文缺少触发或过渡。
- `冲突`：与权威设定、知识状态或能力边界直接相悖。
- `未知`：项目资料不足，不能替角色补设定。

发现问题时，优先补动机、触发、代价或后续反应；不要偷偷修改人物底层设定。若确需变更正式人物设定，转入 [正史管理](canon-management.md) 并等待明确授权。
