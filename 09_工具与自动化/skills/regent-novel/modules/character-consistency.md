# 人物一致性

用于规划、正文和审稿中的人物校验。目标不是让人物永远理性或稳定，而是让重要行为与既有设定和当前情境相容。

## 按需核对

只检查与当前任务有关的项目，不要求每次完整走表：

1. **目标与知识**：人物此刻在意什么，已经知道什么。
2. **能力与状态**：专业、体能、经验、伤病、疲劳和情绪是否影响行为。
3. **关系位置**：面对当前对象时，人物愿意开放到什么程度。
4. **声音与反应**：表达方式是否属于这个人物和场景，而非机械展示标签。
5. **长期变化（如有）**：若本场意味着稳定的人物变化，是否有此前积累；普通情绪波动和临场反应只需有当前触发。

人物比平时多说、少说、更直接、更沉默或暂时判断失准，都不自动构成冲突。不得用固定台词数量、句长和场景岗位判断人物是否一致，也不为避免写反而把人物统一写得谨慎、克制和正确。

## 判断级别

- `通过`：现有设定与场景足以支持。
- `需铺垫`：可以成立，但缺少必要触发或过渡。
- `冲突`：与正式设定、知识状态或能力边界直接相悖。
- `待定`：涉及重要正史而资料不足，不能擅自锁定。

重要身世、关系历史和长期状态不足时不得补造；不改变底层设定的临场措辞、小动作和普通生活反应，可以依据当前情境自然处理。

发现问题时优先做局部修正。若确需改变正式人物设定，转入 [正史管理](canon-management.md) 并等待明确授权。
