# 项目总控

用于存放项目总体说明、创作目标、语言风格、进度与全局管理文件。

## 当前内容

- [语言风格与叙事基调.md](语言风格与叙事基调.md)：正文规划、起草、修改和文风审查的正式上位标准；锁定“明晰、从容、准确而有质地的电影化现实主义”方向，以及直接／间接书写、现实主义、电影化场景、生活基底、现代白描与克制抒情等执行规则。
- [人物对话总则.md](人物对话总则.md)：对白设计的正式原则；强调性格是倾向而非台词配额，人物声音由关系、状态和具体情境共同决定。

## 使用规则

完整正文起草、章节级润色或专门文风审查前读取《语言风格与叙事基调》；当前会话已经读取且文件未更新时不重复加载。对白本身是任务重点、人物明显写反或需要专项校准时，再读取《人物对话总则》；普通生活对白、局部措辞修改和功能性交流不启动额外流程。人物声音仍以人物档案为准，情节与事实仍以正式大纲、时间轴和专项设定为准。
