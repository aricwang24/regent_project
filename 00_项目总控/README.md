# 项目总控

用于存放项目总体说明、创作目标、语言风格、进度与全局管理文件。

## 当前内容

- [语言风格与叙事基调.md](语言风格与叙事基调.md)：正文规划、起草、修改和文风审查的正式上位标准；锁定“明晰、从容、准确而有质地的电影化现实主义”方向，以及直接／间接书写、现实主义、电影化场景、生活基底、现代白描与克制抒情等执行规则。
- [人物对话总则.md](人物对话总则.md)：重要对白设计与审查的正式原则；强调性格是倾向而非台词配额，人物声音由关系阶段、当前状态和具体利害共同决定，并防止写反与纠偏过度。

## 使用规则

进行正文创作、章节润色或文风审查前，必须读取《语言风格与叙事基调》。涉及关系推进、冲突、秘密交换、情感坦白或重大决定的重要对白时，再读取《人物对话总则》；普通生活和功能性对白不要求额外启动完整流程。人物声音仍以人物档案为准，情节与事实仍以正式大纲、时间轴和专项设定为准。
