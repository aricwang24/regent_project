# 项目总控

用于存放项目总体说明、创作目标、语言风格、进度与全局管理文件。

## 当前内容

- [作品定义与主题.md](作品定义与主题.md)：作品定位、核心主题、林峻中心视角、摄政王第二主角及机械、伙伴与北美生活的上位定义。
- [语言风格与叙事基调.md](语言风格与叙事基调.md)：正文规划、起草、修改和文风审查的正式上位标准；追求现实主义底色下清晰而不简陋、精致而不矫饰、丰润而不臃肿的现代公路小说语言，允许适度华美、细腻和抒情，同时要求情绪、修辞与事情本身相称。
- [创作工作流.md](创作工作流.md)：单元大纲、章节方法和文件职责的正式工作流；规定同一份单元大纲内部使用“本章主线／必须保留／可用素材”三层结构，不为每章重复建立内容相同的执行文件。
- [人物对话总则.md](人物对话总则.md)：对白设计的正式原则；强调性格是倾向而非台词配额，人物声音由关系、状态和具体情境共同决定。

## 使用规则

完整章节起草、完整章节重写或章节级整体润色前，固定读取《作品定义与主题》《语言风格与叙事基调》《创作工作流》和《人物对话总则》四份正文核心总控文件。当前会话已经读取且文件未更新时不重复加载。

局部改句、单段微调、人物声音测试和独立场景试写不自动启动完整核心包；涉及整章结构、正文生成方式或大纲转译时应启动。人物声音仍以人物档案为准，情节与事实仍以正式大纲、时间轴和专项设定为准。

《设定索引》《正史优先级与文件边界》《待定与回查事项》属于导航、来源管理和按需核查文件，不因完整章节写作而无差别全部加载；只有任务实际涉及路径、冲突、待定事实或历史禁读边界时再读取。
