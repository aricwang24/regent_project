# 设定索引

> 状态：当前正式设定入口。人物采用独立档案，按任务最小化读取。
> 主题优先级：涉及作品气质、核心主题、摄政王的结构意义、冒险与伙伴关系时，以《作品定义与主题》当前版本为最高依据。历史快照、迁移映射和旧修订记录不得覆盖当前模块。

## 开始工作时读什么

| 任务 | 最小读取集合 |
|---|---|
| 讨论全书方向 | `作品定义与主题.md`＋`总体故事线.md`＋`九卷分卷总纲.md`；时间问题再读`总时间轴.md` |
| 讨论具体人物 | 对应人物独立档案＋直接相关人物关系；只在涉及时间阶段时补读大纲或时间轴 |
| 对白专项或关系转折 | 当前场景＋在场人物档案＋直接相关人物关系；出现写反或需要校准时再读`人物对话总则.md` |
| 讨论车辆剧情能力 | `车辆体系上位摘要.md`；具体参数再读对应专项机设 |
| 讨论事故、北境或南美主线 | 对应分卷或单元纲要；路线、时间和技术问题分别按需补读专项文件 |
| 形成分卷或剧情单元 | `作品定义与主题.md`＋`总体故事线.md`＋`九卷分卷总纲.md`＋相关人物 |
| 形成章纲 | 当前卷／单元纲要＋相关人物；前后章、时间轴和研究资料按需读取 |
| 生成日常事件 | 相关卷纲＋相关人物＋适用的地点或日常素材 |
| 写连续正文 | 当前单元／章纲＋出场人物＋最近正文；文风、时间轴、状态表、车辆和研究资料只在实际涉及时补读 |
| 独立试写或局部修改 | 目标片段＋直接相关人物和场景，不自动扩大为完整章节加载 |

已经在当前会话中读取且没有更新的文件，不为完成流程重复读取。
