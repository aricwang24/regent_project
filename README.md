<h1 align="center">《摄政王·远岬》</h1>

<p align="center"><strong>现实主义底色的现代公路浪漫史诗</strong></p>

<p align="center">从San Diego与Phoenix的双城生活，到猎场、太平洋外海与一台从残骸中诞生的重型房车。</p>

---

## 内容简介

2022年秋，电气工程师林峻去San Diego接刚来读博的妹妹林漪。原本一天的安顿，被空公寓、家具采购和妹妹几乎为零的生活准备拖成了一周。从此，他开始在San Diego与Phoenix之间反复往返：一边是UCSD、公寓和海岸日常，一边是Intel、Mesa的房子、Rafa的车间，以及一辆等待复活的1996 Chevrolet Caprice 9C1。

随着Sam、Nico、Steve等人陆续进入故事，林峻的周末也越来越不像普通周末：Arizona高原的救援、洛杉矶街头摄影、Westport外海装不进船舱的巨型蓝鳍、鹿猎与灰熊、暴雪中的公路，以及永远做不完的车辆返工。工作、家人、旧情、伙伴和机器开始争夺同一份时间。

而Sam那辆朴素的GMC Savana厢式货车，也将在一次事故后被交到林峻手中。林峻没有把它修回原样，而是从残骸中造出一台能让伙伴继续上路的重型V8房车——“摄政王”。

## 作品的核心气质

> 人的一生值得拥有几个真正可靠的伙伴、几台亲手打造的机器，以及一些多年以后仍会反复讲起的传奇冒险。

《摄政王·远岬》写的不是抽象的远方，而是这些人如何在具体地点、具体机器和具体麻烦中共同生活：谁负责开车，谁能修好故障，谁在真正危险时做出判断，谁又会在回到家以后继续收拾残局。
