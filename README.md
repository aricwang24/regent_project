<h1 align="center">《摄政王·远岬》</h1>

<p align="center"><strong>现实主义底色的现代公路浪漫史诗</strong></p>

<p align="center">从San Diego与Phoenix的双城生活，到猎场、太平洋外海、落基山、北冰洋与泛美公路。</p>

## 内容简介

2022年秋，24岁的林漪来到San Diego攻读博士。她的哥哥林峻是一名在Intel Chandler工作的电气工程师，原本只准备替妹妹接机、安顿一天，却因为一间没有家具的公寓、完全空着的冰箱和林漪远低于预期的独立生活能力，被留在了南加州整整一周。

这次接机打乱了林峻原本稳定的生活。他开始在San Diego与Phoenix之间反复往返：一边是妹妹的校园、公寓、超市、外卖和海岸周末，一边是Intel的验证平台、Mesa的房子、Rafa的修车厂、自己的车库，以及一群早已进入他生活、却彼此并不完全认识的人。

在Phoenix，林峻接手了一辆衰老但比例迷人的1996 Chevrolet Caprice 9C1。原本只是想让它重新好开，项目却在416发动机、强化4L80E、抓不住地面的旧轮胎和不断膨胀的预算中，逐渐变成代号“MARSHAL”的高性能老警车。与此同时，资深工程师Sam驾驶着一辆朴素实用的GMC Savana 3500厢式货车，带林峻进入Arizona高原、猎场和真正需要现场判断的户外生活。

第一卷里，林峻会陪妹妹在南加州重新搭起生活，会跟着纪实摄影师Nico走进Skid Row与Griffith Observatory，会和老朋友Steve在Westport外海追逐一条大到小船根本装不下的蓝鳍金枪鱼，也会在第一次完整承担鹿猎时，眼看刚刚得到的猎物被一头巨型灰熊夺走。车库、校园、公路、枪店、码头、超市、办公室和朋友的公寓，共同构成这个故事最初的世界。

那时，“摄政王”还不存在。Sam的Savana只是一辆经过实用化布置的厢式货车：能载人、睡觉、做饭、装工具，也能在普通周末把伙伴带进山里。直到一次落基山区事故将它变成残骸，林峻才接过这辆车，几乎拆至空壳，开始重建一台能够让Sam重新进入、乘坐甚至驾驶的重型V8房车。

摄政王由此诞生。它不是开篇就已经完成的梦幻房车，而是一项持续数年的共同工程：动力、底盘、电气、储水、供暖、隔音、影音、摄影、狩猎、极寒、无障碍和救援能力不断被加入，又在故障、事故、超重、返工和真实使用中被一遍遍推倒重来。Sam、Rafa与林峻对可靠性、性能和复杂系统的不同理解，也让这台车的每一次升级都带着争论、笑料和代价。

随着摄政王逐渐成形，林峻的生活也不再只是双城通勤。沈嘉宁进入Intel与Phoenix生活圈；林漪、Nico、Steve、Sam、Rafa以及旧日关系彼此交汇；工作、家人、爱情、车辆和伙伴开始争夺同一份时间。林峻最终离开Intel，在Bozeman附近建立北方整备基地，随后把这台从事故残骸中重生的机器开上育空、阿拉斯加、Dempster Highway、墨西哥、中美洲、安第斯、Atacama、巴塔哥尼亚与火地岛。

而当一路南下的旅行在Buenos Aires突然断裂，故事也会从公路、营地与车库，转入一场横跨南北美洲的调查、营救和正面对抗。此前积累的工程能力、伙伴关系、车辆项目和共同记忆，将在终局中被全部重新调用。

这不是一篇从头到尾只写房车参数的改装文，也不是把北美当成风景布的旅行游记。它写车辆为什么会坏、项目为什么会失控、猎物为什么带不回来、朋友为什么仍愿意再次同行，也写公寓采购、远程办公、房贷、做饭、修车、道路天气、地方规则和关系中的隐瞒与依赖。故事里的机器、地点和知识，都必须通过人物真正做过的事情进入。

## 主要内容

- **San Diego—Phoenix双城生活**：UCSD校园、公寓安顿、Intel工程工作、Mesa住宅、低密度城市出行和南加州海岸日常。
- **车辆与工程项目**：Golf Alltrack、MARSHAL／1996 Caprice 9C1、Sam时期的Savana，以及后来由事故残骸重建的“摄政王”。
- **现代北美户外**：鹿猎、灰熊夺食、太平洋蓝鳍海钓、滑雪、露营、飞钓、国家森林、高原道路和极寒公路。
- **伙伴与亲密关系**：家人、老友、导师、恋人和长期亲密关系逐渐进入同一生活圈，产生合作、依赖、隐瞒、嫉妒与真正的共同经历。
- **长期路线**：美国西部与加拿大落基山、育空和阿拉斯加、北冰洋、墨西哥和中美洲、秘鲁与安第斯、智利、巴塔哥尼亚、火地岛、Buenos Aires与迈阿密。
- **生活百科式细节**：车辆、住房、工作、枪械、摄影、烹饪、补给、法规、海运、清关、维修和地方文化通过行动自然进入小说。

## 作品的核心气质

> 人的一生值得拥有几个真正可靠的伙伴、几台亲手打造的机器，以及一些多年以后仍会反复讲起的传奇冒险。

《摄政王·远岬》允许一章只因为一次海钓、一次修车、一次雪夜被困或一顿共同做成的饭而成立。重大事故和关系断裂会持续改变后续生活，普通故障、迷路、空军、取消行程和临时返工，也可以只是后来被反复拿出来取笑的一段经历。

它关注的不是抽象地歌颂“远方”，而是这些人如何在具体地点、具体机器和具体麻烦中共同生活：谁负责开车，谁能修好故障，谁在真正危险时做出判断，谁又会在回到家以后继续收拾残局。
